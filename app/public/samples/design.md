# Orion App: Design Doc (January 2026)

## Goals
The Orion app handles registrations, schedules, payments and check-in for Orion Fest.

## Architecture
We will use MongoDB as the main database because the team knows it from the web dev workshop.
The frontend is Next.js deployed on Vercel.

## Check-in
Check-in method is still open: NFC wristbands or QR codes?

## Owners
Priya owns the backend. Sneha owns the design system.
